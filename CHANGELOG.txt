SECURE CHAT APPLICATION — DEVELOPMENT LOG

v0.1 — Project Initialization
- Set up the C++ client-server project structure.
- Established TCP socket-based communication.

v0.2 — Server Implementation
- Implemented server socket creation and configuration.
- Added bind(), listen(), and accept().
- Configured the server to listen on port 54000.

v0.3 — Client Implementation
- Implemented client socket creation.
- Added server connection using 127.0.0.1:54000.
- Established client-server connection.

v0.4 — Basic Communication
- Implemented send() and recv().
- Enabled message exchange between client and server.

v0.5 — Continuous Chat
- Added continuous communication loops.
- Enabled multiple messages to be exchanged within a single connection.
- Improved connection and message-handling flow.

v0.6 — User Input
- Replaced hard-coded messages with user-entered messages.
- Added getline() for handling complete messages.

v0.7 — Graceful Disconnect
- Added /quit command for the client.
- Implemented graceful client disconnection.
- Added handling for recv() returning 0.
- Improved socket cleanup and connection termination.

v0.8 — Multi-Client Support
- Refactored server-side client handling into handleClient().
- Added std::thread for concurrent client handling.
- Modified the server to continuously accept new clients.
- Enabled multiple clients to maintain independent connections.

v0.9 — Client Management
- Added a shared list of connected client sockets.
- Added std::mutex for thread-safe access to the client list.
- Added automatic removal of disconnected clients.
- Improved connected-client tracking and client lifecycle management.

CURRENT STATUS
- Basic TCP chat communication is functional.
- Continuous messaging is functional.
- Graceful client disconnection is implemented.
- Multi-client support is functional.
- Concurrent client handling using threads is implemented.
- Connected clients are tracked using a thread-safe client list.
- Disconnected clients are automatically removed from the client list.
